# Bilingual Development Prompts

This collection contains 50 Chinese–English prompt pairs
(100 language-specific texts).

## Files

- `bireg_development_pairs_50_v1.jsonl`: paired prompts and source metadata.
- `CURATION_NOTES_zh.md`: curation notes, exclusions, and text-review notes.

Each JSONL record contains a prompt identifier, Chinese and English texts,
and source metadata. Original identifiers are retained and are not consecutive.

The collection was curated from 59 historical pairs. It documents the
retained development materials; it does not establish the exact membership
of the original development set.

The archived texts are preserved unchanged. Known translation-review
points are documented in `CURATION_NOTES_zh.md`.

These development prompts are separate from the English and Chinese-source
main-experiment evaluation collections.
