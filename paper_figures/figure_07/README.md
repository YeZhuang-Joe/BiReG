# Figure 7 — Ablation of the LLM Planner

This folder contains six source PNG images comparing the regional generation pipeline without and with the LLM planner on three compositional examples.

## Image mapping

| Case | Relationship | Without LLM planner | With LLM planner |
| --- | --- | --- | --- |
| (a) | Boy in front of elderly man | `fig07_a_without_planner.png` | `fig07_a_with_planner.png` |
| (b) | White cat on black dog's head | `fig07_b_without_planner.png` | `fig07_b_with_planner.png` |
| (c) | Cat on dog's head; dog in front of wooden box | `fig07_c_without_planner.png` | `fig07_c_with_planner.png` |

In the configuration without the LLM planner, split ratios and regional prompts are specified using fixed rules. In the full configuration, these structured inputs are generated by the LLM planner.

## Complete prompt pairs

`prompts.jsonl` contains three UTF-8 JSON records, one per case. Each record includes the complete Chinese description, its corresponding English translation, the development-prompt identifier, and the two image filenames.

The descriptions and translations are taken from the released development collection:
[`data/development_prompts/bireg_development_pairs_50_v1.jsonl`](../../data/development_prompts/bireg_development_pairs_50_v1.jsonl).

| Case | Development prompt | Source record |
| --- | --- | --- |
| (a) | BIREG-053 | PDF-U01 |
| (b) | BIREG-054 | PDF-U02 |
| (c) | BIREG-055 | PDF-U03 |

The short relationship descriptions in the figure summarize these complete prompts. The English wording is the corresponding translation retained in the development collection.

## Manuscript presentation

Figure 7 uses two rows and three columns. The top row is labeled `w/o LLM planner`; the bottom row is labeled `w/ LLM planner`. Configuration labels are added inside the images using LaTeX overlays. The three columns correspond to cases (a), (b), and (c).

The manuscript accesses the PNG files under `paper_figures/figure_07/`.
