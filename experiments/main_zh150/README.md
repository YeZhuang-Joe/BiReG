# Chinese Main Experiment — ZH150

This directory will contain the materials needed to reproduce
the main experiment on the frozen 150-prompt Chinese-source subset:

- Original Chinese prompts, source identifiers, and annotations.
- Frozen English translations and subset provenance.
- Frozen plans, fallback directives, and generation configurations.
- Generation and scoring scripts.
- Archived scores and statistical analysis scripts.
- Image download links and file checksums.

Experiment materials are being organized for release.
